发现的问题与方法偏差：
1. Android 的 File(directoryPath).setLastModified 不支持目录，错误原文：
   FileSystemException: Cannot set modification time, path = '/data/data/com.icodejoo.mova.mova_example/cache/mova_thumbs/engine_old' (OS Error: Is a directory, errno = 21)
   首次脚本三轮均因该夹具问题中断，不能算完整验收；原始输出保留在 pilot-file-mtime-error/。
   修正后的验收仍记录此 API 的真实错误，再以 File.setLastModified 设置临时 stamp，
   读取真实文件 mtime，经 libc.utime 写入目录，最后 Directory.stat 确认实际年龄。
   这一步偏离了“仅直接用 File.setLastModified 设置目录”的预想，但没有修改或注入 provider。
2. PC 构建遇到提交内存不足：
   Native memory allocation (malloc) failed to allocate 1559856 bytes. Error detail: Chunk::new
   Could not reserve enough space for object heap
   通过只对脚本设置 Gradle launcher 128MB / daemon 1536MB、单 worker、单次 daemon、
   Kotlin in-process 完成 release 构建；回收的 Kotlin 孤儿进程确认来自本次失败构建。
3. --no-pub 沿用开发模式插件注册代码，release Java 编译错误原文：
   程序包dev.flutter.plugins.integration_test不存在
   去掉 --no-pub 后由 Flutter 重新生成正确的 release 注册代码。
4. 本次验收未发现两处目标库实现的功能失败。lib/ 无修改；未 commit/stash/reset。
