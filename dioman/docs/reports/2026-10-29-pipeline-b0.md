正式测量在旧全量测试和默认测试完成后运行，没有与本任务的分析、构建或测试并行；不控制机器上其它会话的外部负载，不能把离散度归因到某一特定外部进程。

```powershell
dart run benchmark/legacy.dart > benchmark/run-1.json
dart run benchmark/legacy.dart > benchmark/run-2.json
dart run benchmark/legacy.dart > benchmark/run-3.json
python benchmark/summarize.py
```

三次调用都实际执行并退出 0。每次进程内按 S1→S6 测一轮，各场景独立构造与销毁。adapter 每次新建 ResponseBody，真实 Dio JSON Transformer 每次得到新的信封 Map；没有路由表、网络 IO 或人为延迟。bench 自身不依赖 `test/support/`。

S1 裸 Dio；S2 旧 install 无插件；S3 全部旧插件（含有效 token、在线 offline、无命中的 mock adapter、空输出的日志/通知）且每次递增 query 保证 memo 未命中；S4 同样全插件、固定 key、TTL 一小时，计时前填充；S5 仅 key+share(start)，每次 100 并发同 key，整组结束再开始下一组；S6 仅 retry(max=2)、每次新建嵌套 data 的 POST，始终成功、不重试。

ops 是整次 operation：S1–S4/S6 为单请求，**S5 为 100 请求一组**。S5 的吞吐是组/秒，延迟是整组延迟；不能与单请求延迟直接比较。均值为操作耗时算术均值；p99 为排序后的最近秩 `ceil(n*0.99)`。构造、自检、预热、排序和 dispose 不计入测量；ops/s 的总时钟包含采样记账成本。JSON 保留秒数、操作数、发送数和每操作请求数。
