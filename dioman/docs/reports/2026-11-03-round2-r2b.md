### 三平台分类核对

选择**条件导入 stub**，没有只依赖 DioExceptionType：Dio 的 unknown 仍可能包住 SocketException、HttpException、TlsException，去掉 cause 检查会将这三类原生网络错误误判 internal。VM 实现保留原 is 判定；非 IO 实现返回 false，跨平台网络失败仍由 connectionError/badCertificate 判为 network；FormatException 仍为 parse，其余 unknown 仍为 internal。

探针位于 coverage/r2b_platform_probe.dart，条件夹具与 JS/Wasm 产物同在 coverage，不入库。实际执行：

```sh
dart run coverage/r2b_platform_probe.dart
dart compile js coverage/r2b_platform_probe.dart -o coverage/r2b-probe.js
node coverage/r2b-run-js.cjs
dart compile wasm coverage/r2b_platform_probe.dart -o coverage/r2b-probe.wasm
node coverage/r2b-run-wasm.mjs
```

使用 Dart 3.13.0 与 Node v24.11.0；Node 中设置 self 后执行 dart2js，Wasm 通过生成的 mjs compile/instantiate/invokeMain 实际运行。不是仅检查编译成功。

| 输入事实 | VM / dart2js / dart2wasm 输出 |
|---|---|
| connectionTimeout/sendTimeout/receiveTimeout | timeout |
| badCertificate/connectionError | network |
| badResponse | 无内核失败标记 |
| cancel | cancel |
| unknown、transformTimeout、程序 StateError | internal |
| unknown + FormatException | parse |
| socket/http/tls 网络事实 | network |

三者 14 项 JSON 逐字段相同。[完整输出](round2-r2b-evidence/platforms.json)。**输入边界**：浏览器没有 dart:io 的三个类，不能在 JS/Wasm 构造它们；这三个表项在 VM 用真实 IO cause + unknown，在 JS/Wasm 用等价的 connectionError。其余 11 项是三后端同一输入。VM 纯单测另核对三种真实 IO 类和 stub 的不猜测规则，不用类型名字符串模拟异常。
