## HTML 与 parse 的明确口径

| 响应 | 默认 expectJson=false | expectJson=true |
|---|---|---|
| 非法 JSON，声明 application/json，HTTP 502 | parse / status=502 / httpStatus=502 | 同左 |
| 非空 HTML，声明 text/html，HTTP 200 | ok，保留文本 | parse / status=200 |
| HTML 却声明 application/json，HTTP 200 | Dio 解码 FormatException → parse | 同左 |
| JSON 空体 | ok / data=null | 同左 |

严格模式这次明确为“不依赖服务端 MIME，拒绝 2xx 非空文本”，修复旧实现只认 JSON MIME 的限制。testkit 面向 JSON API，执行器显式 `expectJson: true`；库默认文本契约保留。自定义 responseDecoder 的 null 返回仍保留。没有在执行器手动 JSON 解码、转换信封或重判业务状态。
