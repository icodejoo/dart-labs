## 规格不清与保守取舍

### 需要终审确认

1. **ready 连续三次都不稳定：终审已裁决**。连续轮换属于正常竞态；最多调用 ready 三次，耗尽后注入最后一次生成的 patch，状态记录该次调用前的 token 快照，避免无限追赶。随后 401 时若快照与当前 token 不同，默认 replay，不触发刷新。期间登出仍返回 unauthenticated。
2. **breaker reset 管理能力**：规格管理 API 枚举 stateOf/isOpen/bucketCount，而迁移 rule.md:317 与 unit.md:110 要保留清桶行为。因此在 `DiomanBreakerApi` 额外保留 `reset()`，并验证旧窗口不写新桶。清表不会强行取消已放行的传输；dispose 同样清表。
3. **跨 B4 的 39 条组合行**：本批没有实现 share/cache/mock，也没有用伪装成这些插件的 TestPlugin 声称真实集成通过。每行已有 B3 对应边界用例；其完整组合必须在 B4 承接。这与 B2 报告对跨批组合分段验证一致，但仍需终审确认本批范围，不能据此宣称迁移总账全部关闭。具体行号全部列在下文。
4. **旧异常专属字段：终审已裁决**。删除旧异常后由 DiomanBreakerApi.keyOf(request) 与 retryableAt(key) 承接 bucketKey/retryableAt。keyOf 使用含请求覆盖的 keyBuilder，不建桶、不改状态；retryableAt 只在 open 返回开启时 openedAt + 当时生效的 resetDuration，否则为 null；到期查询不迁移状态。unit.md:112–113 分别由这两个方法的真实回归承接。

### 已按规格处理

- auth 的请求级 `DiomanAuthOptions(enabled:true)` 强制保护；`call` 中的裸 true 仍表示沿用插件配置。没有显式强制时，isProtected 每次尝试入口只求值一次，同次重放不重算。
- 默认 auth 读逻辑状态；onFailure 不接收 internal/cancel，network/timeout/parse 仍交给它。自定义 onFailure 返回 Others 保留原响应。
- 会话按失败请求实际注入的原始 token 比较，旧请求的过期与刷新失败不清新 token；重新登录获得同名 token 后可再次通知。存储接口没有独立会话代号，沿用旧版按 token 值识别的契约。
- 请求侧 ready/onFailure/通知等待使用 ctx.wait；每次返回后检查 ctx.cancelled。共享刷新内部不受请求取消中止，包含失败清会话与过期通知；请求只取消自己的等待。Future(() => onRefresh(...)) 强制异步发布窗口，成功或失败 finally 都释放。
- 本地无 token 每请求通知 denied（缺省 expired）一次，不与失败会话的 expired 去重混用。重放之前重新检查凭证，登出后不重放。
- retry.max 非正数仍 markReplayable；shouldRetry 在有重试预算时也接收成功响应。Retry-After 空白为零，日期读 DiomanClock，独立上限不叠加 jitter。
- breaker 保留软上限和非正数不钳制语义：只回收没有在途、没有失败且 closed 的桶；open/halfOpen/在途/有连续失败的桶不能因容量丢失。只读查询不触发状态迁移。
- 不可克隆 Stream 沿用 B1 回退原引用并 debug 告警的契约；回环用可重复订阅的 Stream 证明插件实际重发，不承诺单订阅流能重新消费。

## axp 十条教训回归

| # | 教训 | 新回归完整标题 |
|---|---|---|
| 1 | 每个 await 后取消重查、订阅前取消 | [DiomanContext.wait] 退避取消含订阅前取消，禁止再次进入内层；[DiomanContext.cancelled] ready 与 onFailure 异步返回后重查取消，不通知不进入内层；[DiomanContext.wait] 取消未完成的 ready onFailure denied expired 回调立即收尾，迟到异常被消费；[DiomanAuth.expiresAt] 主动刷新等待取消也不终止共享刷新 |
| 2 | ready 换 token 重做并记录实际注入值，常量 3 次 | [DiomanAuth.ready] ready 期间换 token 重做并记录实际注入值，最多三次 |
| 3 | 刷新成功、重放之前重查本地凭证 | [DiomanAuthFailureAction.replay] 刷新成功后登出不重放，ready 期间登出也本地拒绝 |
| 4 | 发起者、等待者和 cancelAll 只取消自身，刷新仍完成 | [DiomanAuth.onRefresh] 发起者等待者取消和 cancelAll 不终止刷新，成功写 token 失败清会话 |
| 5 | 同步/异步 onRefresh 抛错释放窗口，debug 告警一次 | [DiomanAuth.onRefresh] 同步与异步抛错释放窗口，失败清会话只通知一次并可同名重登 |
| 6 | I7 嵌套 Map/List 与原地修改 Transformer | [DiomanContext.markReplayable] retry 与 auth 各自保护嵌套请求体，Transformer 原地修改不污染重放 |
| 7 | max 为 0 或负数仍 markReplayable，不重试 | [DiomanContext.markReplayable] max 零与负数仍声明克隆且不重试 |
| 8 | onFailure 类别边界、isProtected 尝试一次/重放不重算 | [DiomanAuth.onFailure] internal cancel 不路由，network timeout parse 仍路由且默认 others；[DiomanRetry.max × DiomanAuth.onRefresh] 刷新不占重试预算，isProtected 每次尝试一次，重放不重算 |
| 9 | 每个本地无 token 请求 denied 一次，缺省回退 expired | [DiomanAuth.onAccessDenied] 本地无 token 每请求通知一次，空串等价未登录，默认回退 expired |
