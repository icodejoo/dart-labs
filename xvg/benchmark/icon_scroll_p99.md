# 1,000 图标冷滚动光栅 p99

**结论**。F2 去掉图标门槛里的重复几何准备，714 份语料的路径数和 SSE 字节与 F 相同。Windows 的 F 和 F2 都与 C1 持平。真机 F2 同步 FFI 墙钟 p50/p95/p99 为 99/187/288 µs，C0 为 98/190/281 µs。在核 p99 仍有 19 µs 差距。无追踪滚动的光栅 p99 和长帧数在六区组检验中均无显著差异。第 2 步已将大部分长光栅帧归因到 Vulkan 等待交换链缓冲区释放。逐轮数据见[原始数据](raster_cache_auto_icon_p99_raw.json)。

## 第 1 步 · 冷滚动复测

最初四轮 C0 无 >10 ms 光栅帧，F 有 6 帧，其中 3 帧在 1.390–1.402 s。随后按 C0、F、G 做六区组交替，平均漏帧/轮为 2.33/3.67/3.67，光栅 p99 均值 8.67/11.51/11.53 ms。G 将两门槛都设为 `usize::MAX`，并令预筛恒返回 false。C0/F 的光栅 p99、>16.67 ms 帧数配对置换 p=0.28125/0.0625。1.380–1.420 s 三档均无 >10 ms 光栅帧。

## 第 2 步 · Android 构建与长帧追踪

只将 Android API 21 改为 24，把 C0 重建为 C1。无追踪六区组 C0/C1/F 的光栅 p99 均值为 9.84/8.37/13.10 ms，C0/F 配对 p=0.25。追踪下 C0/F 的光栅 p99 为 12.27/9.40 ms。42 帧中 37 帧主要耗在 Vulkan 交换链或 fence 等待，24 次漏节拍均有 `PipelineFull`。主要等待链为 `AcquireNextImageKHR → dequeueBuffer → waitForBufferRelease`。C0/F 各 2,694 次同步 FFI 的墙钟 p50/p95/p99 为 90/182/265 和 97/193/315 µs，在核 p99 为 230/237 µs。

## 第 3 步 · 廉价合并门槛

**Windows release**。Rust 1.100.0，同一逻辑核，三档共 36 个交替区组。每轮预热 1,000 图标，再对同一批图标完整调用 `parse_svg` 和实际 FRB SSE 编码，`currentColor=None` 与真机一致。单图分位数汇总全部逐图耗时，总耗时分位数按轮计算。括号内为 Q1–Q3。

| 档 | 单图中位数 µs（IQR） | 每轮中位数 ms（IQR） |
| --- | ---: | ---: |
| C1 `c78eda18` | 13.7（11.5–16.2） | 14.555（14.362–15.024） |
| F `6e9bee60` | 13.6（11.5–16.1） | 14.487（14.326–14.713） |
| F2 | 13.5（11.4–16.1） | 14.571（14.282–14.869） |

F2 总耗时比 C1 高 0.11%，在其 IQR 内。PC 两次入参设置下都未复现 F 的稳定回退。这 1,000 个图标均为单条填充路径，24×24 视口与 viewBox 相等，原预筛会重复准备几何，恒等变换也让它跳过逐点有限性扫描。

**实现与语料**。预筛只统计可见路径和 `path.data()` 原始点，达到 100 条或 15,000 点即停。达标后合并阶段沿用原可绘制几何判定。普通场景的 `collect` 专门化会消除逐条追加判断和组边界重置，`SceneBounds` 回到合并前的字段布局。`convert_path` 的准备拆分和 viewport 检查没有给图标增加分配。F/F2 714/714 路径数和 SSE 字节一致，其中 `effect__Gauss-prime-numbers.svg` 按 XML 声明从 ISO‑8859‑1 解码。有一个语料外的已验证边界。两枚可合并矩形加一条展开后达标的虚线，原始点数未达新门槛，F 输出 2 条路径，F2 输出 3 条。

**SM-A566B**。Flutter 3.50.1 profile、Impeller Vulkan、120 Hz。同步 FFI 用第 2 步的计时插桩与 Perfetto，各 4 轮、3,592 次。墙钟 p99 的区组差均值为 −0.5 µs，双侧配对置换 p=1.00。在核 p99 为 C0/F2 236/255 µs，p=0.50。

| 档 | FFI 墙钟 p50/p95/p99 µs | 漏帧/轮 | UI p50/p95/p99 ms | 光栅 p50/p95/p99 ms | 光栅 >10/>16.67 ms 总数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| C0 | 98/190/281 | 3.17 | 2.81/4.06/6.20 | 3.68/4.82/8.90 | 8/5 |
| F2 | 99/187/288 | 2.83 | 2.61/3.92/9.06 | 3.48/4.71/8.14 | 4/3 |

滚动为六区组无追踪交替，每轮新进程冷滚动 1.65 s，表中分位数为逐轮最近秩分位数的均值。漏帧、光栅 p99、>10 ms 和 >16.67 ms 帧数的双侧区组置换 p 分别为 0.75、0.78125、0.375、0.625。
