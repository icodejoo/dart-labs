# 静态 SVG 路径合并 v4

**web-543 的回退来自矩形快路径被合并后的通用 stencil-and-cover 替换。** 真机 VM Timeline 单次追踪中，raster 线程的 `DoMakeRasterSnapshot` 从 **176.49 → 216.17 ms**，并新增 `Clip Pipeline V#1` 和 `SolidFill Pipeline V#2`。管线编译合计 0.85 → 1.43 ms。Flutter profile 的埋点未单列 tessellation、stencil 和 cover 耗时，阶段归因依据是管线变化、引擎的矩形派发与 stencil-and-cover 实现，以及 A 档回测。82,181 条原始路径都是单轮廓矩形。旧合并档的 1/2/3/4/5 轮廓路径数分别为 36,592/19,320/2,175/91/12，裁剪内路径和跨裁剪边界合并均为 0。

**web-481 的差异来自独立绘制与复合路径的光栅覆盖和颜色舍入。** 旧档的 375 个差异像素位于 873×1264 捕获图的 x=3–664、y=379–857。原几何间隙门槛在实测缩放下约为 3.4 物理像素。A 保留 `DrawLine` 后，最大通道差 23 降到 1，还剩 89 个像素，分布在裁剪内的填充及多段描边边缘。B 让含描边的活动裁剪子树独立绘制，两轮均为 **0 像素差**。该图路径数依次为 12,511 → 3,082 → 5,801 → 12,511，B 的快照比自身配对 C0 慢 32.0%。

A 保留微型轴对齐填充矩形和独立直线，矩形边长上限取 1,024 参考长边的 8 像素。B 在 A 上保留含描边的裁剪组。两档均使用 `1024/1024`，即不限跨度、每组最多 1,024 条原始路径。
