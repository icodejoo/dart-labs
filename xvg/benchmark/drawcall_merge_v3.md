# 静态 SVG 路径合并 v3

**放宽跨度对 web-481 有收益，对 web-543 仍有回退。** 从 128/128 放宽到 1024/1024，web-481 首次快照快 28.4%，web-543 快 3.1%。相对 C0，web-481 快 45.0%，web-543 慢 19.5%。默认档为 256/128。

## 真机

SM-A566B，Flutter 3.50.1 profile，Impeller Vulkan，120 Hz。两轮反转档位与样本顺序，取均值。②b 计 Picture 冷录制，③ 计原生 `DoMakeRasterSnapshot`。每个样本各档只请求一张纹理，web-543 为 872×873，web-481 为 873×518。

| 档位 | web-543 ②b / ③（ms） | web-481 ②b / ③（ms） | web-543 / web-481 变化像素 |
| --- | ---: | ---: | ---: |
| C0 | 237.45 / 176.57 | 52.61 / 60.72 | 基线 |
| 128/128 | 182.64 / 217.70 | 30.00 / 46.66 | 0 / 322 |
| 512/1024 | 188.37 / 217.95 | 25.64 / 38.86 | 0 / 368 |
| 1024/1024 | 182.32 / 210.96 | 25.84 / 33.42 | 0 / 375 |

两轮的像素差一致。两张图的最大 RGBA 通道差分别为 0 和 23，每次比较 1,103,952 像素。本轮跳过转圈和 1000 图标滚动。

## Windows

714 份语料每档各解析一次。按原始顶层路径数 ≥100 或其主几何点数 ≥15,000 准入，曲线控制点也计入。317 份未达标的 SVG 在所有合并档的路径数与 C0 一致。MDI 固定抽 50 个，每库各解析一次，原生 FFI 含 SSE 编码的平均耗时为 **53.20 → 36.75 µs/图**，中位数为 **38 → 34 µs/图**。单轮观察未见额外开销。

| 档位 | 路径总数 | 门槛跳过文件数 |
| --- | ---: | ---: |
| C0 | 642,348 | 全量关闭合并 |
| 128/128 | 578,117 | 317 |
| 512/128 | 562,864 | 317 |
| 512/1024 | 562,864 | 317 |
| 1024/128 | 557,118 | 317 |
| 1024/1024 | 557,111 | 317 |

web-543 的路径数从 82,181 降到 58,190，所有主路径控制点包围盒面积之和从 1.78 增到 3.26 个固有长边平方。覆盖范围扩大可能抵消部分绘制收益。web-481 同一指标从 5.82 增到 61.72，首次快照仍加快，说明面积总和单独不足以预测快照耗时。下一轮可固定组上限，测试每组包围盒面积膨胀率与轮廓数上限，分别量 Impeller 细分和覆盖成本，并以 web-481 的像素差作回归条件。
