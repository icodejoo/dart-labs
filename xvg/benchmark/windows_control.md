# Windows Flutter 路径合并对照

**结论。** web-481、web-415、web-263 的平均录制和首次快照均变快，方向与手机一致。web-543 两项各有两对变慢，录制均值受一轮较慢的 C1 拉动。像素一致性未复现。web-543、web-415、web-481 的最大通道差分别为 79、50、5，手机四图均 ≤1。图标滚动只在 C1 一轮出现长尾，其余五轮均无漏帧或 >10 ms 的光栅帧。三对样本不足以确认稳定的滚动收益。

**环境。** Windows 10 Pro 22H2（19045），i5-13500、Intel UHD 770（31.0.101.4953），Flutter 3.50.1 x64 profile。运行日志为 Impeller OpenGLESSDF，走 OpenGL ES → ANGLE/EGL → D3D11，进程加载了 D3D11、DXGI 和 Intel 用户态驱动。双屏均为 2560×1440、信号 59.9506 Hz，测试位于右侧屏，Flutter 报告 59 Hz，DPR 1.0，外框 640×360、客户区 624×321 物理像素。

**复杂图。** C1 → H，每档三轮算术均值。②b 采用现有冷 Picture 录制钩子，③ 采用与手机对应的原生 `DoMakeRasterSnapshot` 片段。像素比较取 310×450 的预乘 RGBA 图层，三对结果相同。

| 样本 | 路径数 C1 → H | ②b 录制 ms | ③ 首次快照 ms | 变化像素 / 最大通道差 |
| --- | ---: | ---: | ---: | ---: |
| web-543 | 82,181 → 81,691 | 187.59 → 166.92 | 363.36 → 382.69 | 36,007 / 79 |
| web-481 | 12,511 → 5,801 | 51.94 → 32.00 | 63.36 → 45.81 | 3 / 5 |

| web-263 | 5,113 → 1,953 | 19.31 → 11.40 | 105.44 → 39.64 | 0 / 0 |

web-415、web-263 两项均三对变快，web-481 快照三对变快、录制两对变快。web-543 有 25.8% 像素变化，常见变化是同一不透明像素的灰度从 118–120 降到 42。两个 Windows 包只替换 DLL 即可复现。手机用 Impeller Vulkan、120 Hz 和 872×1,266 图层。后端、图层尺寸、刷新率和遮挡条件均有差异，像素回归的具体触发环节尚未定位。

**1,000 图标冷滚动。** 每轮新进程，无引擎追踪，滚动 1.65 s。分位数为逐轮最近秩的均值，漏帧按 vsync 空档计数（两种刷新率读数结果相同），长帧为三轮总数。

| 档 | 漏帧逐轮 | UI p50 / p95 / p99 ms | 光栅 p50 / p95 / p99 ms | UI >10 / >16.67 ms | 光栅 >10 / >16.67 ms |
| --- | ---: | ---: | ---: | ---: | ---: |
| C1 | 0 / 7 / 0 | 1.92 / 3.47 / 4.98 | 2.11 / 11.10 / 31.74 | 0 / 0 | 9 / 5 |
| H | 0 / 0 / 0 | 1.98 / 3.36 / 4.12 | 2.22 / 3.77 / 4.11 | 0 / 0 | 0 / 0 |

C1 光栅 p99 逐轮为 4.32 / 86.59 / 4.30 ms，H 为 2.84 / 4.07 / 5.41 ms。结果与手机「未见稳定滚动差异」相容。手机长尾主要归因于 Vulkan 交换链等待，本次 Windows 仅采集滚动帧计时，长帧来源未归因。

**复现与核验。** 每项顺序 C1、H、H、C1、C1、H。沿用现有安静 runner，采集器在窗口显示后以 `HWND_BOTTOM` 和 `SWP_NOACTIVATE` 再次压底。12 轮均未观测到测试进程进入前台。两份 profile 包的其他 12 个文件逐字节相同，含 Dart AOT。每轮核对实际映射的 `bundle-C1/xvg.dll` 或 `bundle-H/xvg.dll` 文件 SHA-256，与 Rust x64 release 源产物一致。
