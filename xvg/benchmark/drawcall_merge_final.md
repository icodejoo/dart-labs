# 静态 SVG 路径合并定稿

采用 [v4 A 档](drawcall_merge_v4.md)。达到 100 条路径或 15,000 个主几何点才进入合并。同组中画笔相同、绘制顺序连续且带余量凸包相离的路径可合并，不限跨度，每组最多 1,024 条。微型轴对齐填充矩形与独立直线保留独立绘制，低于门槛的图标跳过合并。

SM-A566B，Android 17，Flutter 3.50.1 profile，Impeller Vulkan。每档三轮取均值，交替先跑 C0 和定稿。②b 为冷 Picture 录制，③ 为 Impeller 首次整图快照。像素列为 872 × 1,266 的显示图层预乘 RGBA 对比，三轮结果相同。

**语料**。714 张各解析一次，路径总数 642,348 → 597,212（−7.0%），逐图与 v4 A 一致。web-023 是此前未做真机对照的样本中减量最大的一张，少 2,230 条。

**图标滚动复测（1,000 个）**。沿用上一轮的 profile APK 和 1.65 秒冷滚动入口，120 Hz，C0／定稿按 ABBA BAAB 各跑四轮。采样热状态均为 0，起跑 AP 28.8–31.0 °C、SKIN 29.1–30.3 °C、BAT 27.7 °C。漏帧按滚动窗口内的 vsync 空档计数，表底为各轮指标的算术均值。

**结论**。两档漏帧都在 2–4 次，均值只差 0.25 次。UI / 光栅 p95 均值分别增加 0.13 / 0.25 ms，均在档内波动范围。上一轮的漏帧与 p95 升幅未复现。光栅 p99 四对均升（+1.40–9.27 ms），均值 6.62 → 11.15 ms。定稿每轮各有一帧光栅超过 16.67 ms，C0 四轮均无。定稿的光栅 p99 档内仍在 7.23–15.99 ms 间波动，四对数据支持尾延迟退化信号，稳定幅度仍待确认。

**归因检查**。两份 APK 的应用内容仅 ARM64 的 `libxvg.so` 不同，其余 112 个非签名条目逐字节一致。PC 上 1,000 个图标的 Rust SSE 输出一致。另用两份 APK 对 24 个等距抽样图标做同步 FFI 计时（每档 144 次，含 Rust 解析与 SSE 编码），C0 两轮中位数为 563 / 603.5 µs，定稿为 550 / 583 µs，未测到解析调用变慢。四个长帧的 UI 耗时均低于 4.2 ms，三个集中在滚动约 1.4 秒处，光栅长帧的具体成因仍未定位。逐帧与解析记录见原始 JSON 的 `icon_scroll_retest`。

**核验**。两份 APK 的 so 哈希分别匹配各自构建源，其他 112 个非签名条目一致。素材均在运行时推送，设备临时文件和 adb 转发已清理，刷新率、常亮设置及原 APK 已恢复。[三轮原始数据与完整 SHA-256](raster_cache_auto_merge_final_raw.json)
