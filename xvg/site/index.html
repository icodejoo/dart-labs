xvg

面向 Flutter 的高性能静态与动画 SVG 渲染。Rust（usvg）负责解析，Flutter 自己的 GPU 管线负责绘制，没有 CPU 光栅化；SMIL 动画由 Dart 侧原创引擎驱动。 High-performance static & animated SVG rendering for Flutter. Rust (usvg) parses, Flutter's own GPU pipeline renders — no CPU rasterizer. SMIL animation runs on an original Dart-side engine.

功能导览Feature tour

以包内 README 与 doc/ 为准。Based on the package README and doc/.

静态 SVG（Rust usvg）Static SVG (Rust usvg)

usvg 解析为缓存的 ui.Picture，再交给 Flutter GPU 管线绘制。支持基础形状、<use>、<switch>、<marker>、组 opacity、内嵌 data: 位图。 usvg parses into a cached ui.Picture, drawn by Flutter's GPU pipeline. Shapes, <use>, <switch>, <marker>, group opacity and embedded data: images.

渐变 / clip / mask / filterGradients / clip / mask / filter

线性与径向渐变、clipPath、mask、pattern；filter 目前只有 feGaussianBlur。 Linear & radial gradients, clipPath, mask, pattern; the only filter primitive is feGaussianBlur.

currentColor

源里的 currentColor 通过 XvgTheme(currentColor: ...) 控制，静态与动画路径都生效；colorFilter 可整体重着色。 currentColor in the source is controlled via XvgTheme(currentColor: ...) on both paths; colorFilter recolors the whole image.

SMIL 动画（原创引擎）SMIL animation (original engine)

<animate>、<animateTransform>、<animateMotion>、<set>；一次解析，Dart 侧逐帧采样绘制，每帧无数据跨 FFI。另支持 SVGator 导出的 CSS @keyframes 子集。 <animate>, <animateTransform>, <animateMotion>, <set>; parse once, sample and paint every frame in Dart — no per-frame FFI traffic. A subset of SVGator-exported CSS @keyframes is also supported.

播放控制Playback control

XvgAnimationController：play / pause / stop / reverse / seek、倍速、区间（once / loop / pingPong）、fitDuration；也可由 Flutter Animation<double> 驱动；XvgAnimationQuality 在高并发下自适应跳帧。 XvgAnimationController: play / pause / stop / reverse / seek, rates, ranges (once / loop / pingPong), fitDuration; or drive with a Flutter Animation<double>; XvgAnimationQuality adaptively skips frames under high concurrency.

一个 Widget，五种来源One widget, five sources

Xvg.string / asset / network / file / memory，自动判断走静态还是动画路径；另有 XvgStatic / XvgAnimated，以及可替换 Image.network 的 NetworkXvg 等 ImageProvider。 Xvg.string / asset / network / file / memory auto-select the static or animated path; plus XvgStatic / XvgAnimated and ImageProviders such as NetworkXvg as an Image.network replacement.

预编译原生库Prebuilt native libraries

包内带预编译库（见 prebuilt/），使用方无需 Rust 工具链；pubspec 声明了 Android、iOS、Linux、macOS、Windows 五个 FFI 平台。Android/iOS 等的行为尚未全面实测，见限制。 Prebuilt libraries ship in the package (see prebuilt/) — no Rust toolchain needed for consumers; the pubspec declares five FFI platforms. Android/iOS etc. are not exhaustively tested; see limits.

安全边界Safety limits

静态路径有输入大小（32 MiB）、嵌套（128 层）、引用链、展开预算等限制，超限返回错误；<image href> 只解析内嵌 data: URI。 The static path enforces input size (32 MiB), nesting (128), reference-chain and expansion budgets, returning an error when exceeded; <image href> only decodes embedded data: URIs.

已知限制（如实）Known limits (honest)

  • 静态路径不渲染 <text>（为缩小体积的刻意取舍）；动画路径的 <text> 不受影响。The static path does not render <text> (a deliberate size trade-off); animated-path <text> is unaffected.
  • filter 仅 feGaussianBlur；mask/blur 不嵌套叠加。Only feGaussianBlur is implemented; mask/blur do not nest.
  • 事件类 SMIL begin（如 click）不支持；不支持 gzip SVG（svgz）。Event-based SMIL begin (e.g. click) and gzip SVG (svgz) are unsupported.
  • parse_svg 同步阻塞调用线程，不可信输入请放后台 isolate。parse_svg is synchronous; parse untrusted input on a background isolate.

安装与用法Install & usage

flutter pub add xvg
import 'package:flutter/widgets.dart';
import 'package:xvg/xvg.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Xvg.ensureInitialized();
  runApp(const MyApp());
}

// 字符串 / String
Xvg.string(svgSource, width: 48, height: 48)

// 资源 / Asset
Xvg.asset('assets/icon.svg', width: 96, height: 96)

// 重着色 / Recolor
Xvg.string(svgSource, colorFilter: ColorFilter.mode(Colors.blue, BlendMode.srcIn))

// currentColor
Xvg.string(svgSource, theme: XvgTheme(currentColor: Colors.blue))
// 动画控制 / Animation control
final controller = XvgAnimationController(autoplay: false);
Xvg.string(svgSource, controller: controller, onLoaded: (info) {
  controller.play();
});

// 由 Flutter Animation 驱动 / Drive with a Flutter Animation<double>
Xvg.string(svgSource, animation: myAnimationController,
    animationSpan: const Duration(seconds: 2))

// 替换 Image.network / Replace Image.network
Image(image: NetworkXvg(url))
