# Dial / Counter 绘制测量

本轮只保留基准和验证夹具，生产代码不变。分钟弧段直接合并虽然明显更快，但会改变
圆头接缝的真实像素；新增中心 RepaintBoundary 的收益达不到 10%。

## 运行

```powershell
flutter analyze --no-pub lib test
flutter test --no-pub
flutter test --no-pub --tags benchmark --run-skipped
```

`dart_test.yaml` 声明 benchmark tag，并默认 skip。当前 test runner 不会因为显式
`--tags benchmark` 而覆盖 skip，因此第三条命令需要 `--run-skipped`。
实测单独 `flutter test --no-pub --tags benchmark` 只会报告两个 suite skipped，不会输出数字。
配置 `exclude_tags: benchmark` 也无法被 `--tags benchmark` 重新启用。
这是原请求中两条命令语义的工具限制；没有通过读取父进程命令行等方式绕过 runner。

## 方法与边界

- 环境：Windows，Intel Core i5-13500，Flutter 3.47.0，Dart 3.13.0。
- 原实现基线先于候选测量运行，原始输出保存在 `measurements.txt`。
- 每配置预热 2,000 帧，再测 11 批，每批 1,000 帧；输出批均值的中位数、均值及全部批次。
- painter 测量使用 PictureRecorder + Canvas 直接调用 paint，每帧结束并释放 Picture；
  包含录制开销，不含栅格化、GPU、屏幕刷新时间，也不代表 release 模式表现。
- 原内圈参考逐笔和逐像素匹配生产 painter。随后交错测试参考和合并候选，奇偶批倒序，
  避免把跨进程 JIT、调度和机器负载差异当成收益。独立运行三轮。
- 分层实验使用真实 Dial painter 和中心 `Text('60:00')`，两棵树同时挂载，均已有外层
  RepaintBoundary。候选只给中心添加边界；交错标脏并 flushPaint，测量实际框架重绘。
  动态场景每帧同时标脏中心，模拟中心内容也需更新；不包含文本重排或 widget rebuild。
- 分配观测在计时之外用 Canvas 探针记录 Paint 身份。它不是 VM 堆分配分析。
  drawParagraph 是绘制次数，不能直接当作段落创建次数；Dial 标签每次绘制的确会创建、
  排版并释放一个 TextPainter。Counter 预热后复用段落和列布局。
- 不对耗时设断言；几何和像素验证也归入 benchmark tag，默认测试完全不运行这些夹具。

## 决策和验证

**分钟弧段合并不进入生产代码。** 一小时实际有 59 条普通色分钟弧和 3 条末分钟区域弧。
候选将普通色弧变成一条：drawArc 62 → 4，观测 Paint 63 → 5；完整 Dial 原实现
每帧使用 66 支 Paint，开启标签时另创建 12 个 TextPainter。
尽管几何验证在 192 组方向、总时长和剩余时间组合中证明覆盖区间与颜色一致，
200×200 像素输出仍存在以下差异：

| 配色 | glow | 不同像素 / 40,000 |
| --- | --- | ---: |
| 默认不透明 | false | 819 |
| 普通色 alpha=128/255 | false | 2,265 |
| 默认不透明 | true | 5,578 |
| 普通色 alpha=128/255 | true | 5,247 |

圆头接缝、抗锯齿和发光叠加属于原有视觉输出，几何相等不足以保证像素相等。
候选只存在于测试参考类的 `merged` 分支，像素差异断言保留了拒绝该优化的证据。

**新增 RepaintBoundary 不做。** 静态中心绘制调用确实由 13,001 次降到 1 次，
但整体重绘只改善 1.61%–1.92%，低于 10%；动态中心两种配置均绘制 13,001 次，
新增边界反而变慢。原有外层 repaintBoundary 参数和 widget 树保持原样。
这次未证明添加更多静态/动态环层能获益，也没有为了分层改变 painterBuilder 或中心 builder 契约。

最终检查：analyze 零问题；默认测试 351 通过、2 个 benchmark suite 跳过；
显式启用基准后 6 个测试通过（三轮均通过）。原命令不带 `--run-skipped` 时为 0 运行、2 suite 跳过。
没有修改 lib、example 或 analysis_options.yaml，没有执行 commit / stash / reset / push。
