# 自定义能力盘点：老虎机与拉霸机

> 只读审计原文（2026-11，Codex 逐条核对代码，含 文件:行号）。代码此后有变动，行号仅供定位；已落地项见 CHANGELOG 与 docs/E1_E2_DEVICE_REPORT.md。

已经开放得好的点：

- 滚轮加减速曲线、时长、时基、停止求解器均可配置；每列可配置顺序、速度、方向及停轮延迟。
- 选奖支持注入 `picker/random`，也可通过 `stopEach/playUntil` 完全自行决定结果；中奖及赔付线判定已有回调。
- 背景、圆角、图片、文字、描边、阴影已有配置；支持奖品局部 `painter`、多位置静态/动态 layer、绘制 hooks。
- 普通老虎机提供 `overlayBuilder` 和 `SlotGame.itemGeometry`，支持重复条带、循环副本、窗口裁剪及 Widget 内容。
- 自定义 renderer 能取得 config、layout、frame、图片及帧监听；已有阶段、逐格经过、图片失败、就绪、结束回调。
- 主老虎机支持暂停恢复、隐藏暂停策略、缓存模式、采样质量、语义标签及语义值定制。

以下均已核实源码，并阅读相关测试交叉确认；未修改文件、执行 Git、获取依赖或运行测试。表中“无法覆盖”指现成组件缺少对应替换点；需要接管整个 renderer、玩法或控制器的绕行方式单独说明。
