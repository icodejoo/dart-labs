# 自定义能力盘点：扭蛋机与数字转盘

> 只读审计原文（2026-11，Codex 逐条核对代码，含 文件:行号）。代码此后有变动，行号仅供定位；已落地项见 CHANGELOG 与 docs/E1_E2_DEVICE_REPORT.md。

已经开放得好的点：

- 两者都支持整体 `renderer`、静态/动态 `layers` 和绘制前后 hooks；renderer 能取得 config、layout、frame、图片及帧监听器。
- `CapsuleFrame` 已公开阶段、胶囊坐标/自转、掉落及揭晓进度；`NumberWheelFrame` 已公开盘角、球角、球半径、当前格和目标格。
- 加减速缓动、时长、速度、时间基准、最大帧间隔均可配置；数字盘实际使用可注入的 `stopSolver`。
- 选奖支持 `picker`、随机源、权重、禁用项和服务端结果；暂停/恢复、后台暂停策略已有公共入口。
- 扭蛋奖品卡已有文字、图片、填充、阴影、边框和局部 `painter`；两者已有阶段、结果回调，扭蛋图片失败/就绪回调也已转发。
- 核心扩展类型已由 `extend.dart` 导出，包括 `LuckyRenderer`、`LuckySurfaceData`、`LuckyLayoutInput`、`LuckyTextLine`、`LuckyStopProblem`；额外导入即可使用，不属于完全缺失。
