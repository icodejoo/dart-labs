# 自定义能力盘点：抽签与大乐透

> 只读审计原文（2026-11，Codex 逐条核对代码，含 文件:行号）。代码此后有变动，行号仅供定位；已落地项见 CHANGELOG 与 docs/E1_E2_DEVICE_REPORT.md。

已经开放得好的点

- lots 新增的 `riseEasing / revealEasing / shakeWaveform / layoutAdjuster` 已落盘并导出；现有布局比例、扇形角、签长等均可整体调整，不重复列缺口。
- lots 已能分别替换背景、筒后壁、筒前壁、签身；签文卡支持文字、图片和 `LotsStick.painter`。
- 选号可注入：lots 提供 `picker/random`，lotto 提供 `sampler/random`，均支持外部指定结果。
- 两者都有类型化 frame、逐帧监听、动态 layer 和整体 renderer 替换；通用 SPI 已由 `extend.dart` 导出。
- 已提供阶段、结束、图片失败、就绪回调，以及语义标签/描述、手动暂停恢复和隐藏暂停配置；lotto 另有逐球落槽回调。

本报告仅阅读源码和测试，未修改文件、执行 git、pub get 或测试。下表 **L＝`lib/src/lots/`，T＝`lib/src/lotto/`**；“缺口”指沿用内置玩法时缺少局部覆盖口，整体重写 game/renderer 的成本单独说明。
