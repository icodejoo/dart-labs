# 自定义能力盘点：核心层

> 只读审计原文（2026-11，Codex 逐条核对代码，含 文件:行号）。代码此后有变动，行号仅供定位；已落地项见 CHANGELOG 与 docs/E1_E2_DEVICE_REPORT.md。

**已经开放得好的点**

- `LuckyMotionOptions` 已开放加减速缓动、时长、速度、时间基准、单帧上限和停止求解器；`CurveEasing` 可接 Flutter 曲线。
- `PrizePicker`、随机源均可注入；权重选奖、禁用项和保底已有实现，不属于固定选奖策略。
- `extend.dart` 已导出 Game／Motion／Renderer、主要帧与布局 SPI；`LuckySurfaceData` 提供配置、布局、帧、图片及独立通知器。
- `LuckyLayer` 支持四个插入位置、静态缓存、动态绘制；`LuckyItemOverlay` 支持按条目几何跟随运动。
- `LuckyFill.gradient(Gradient)` 已支持 Flutter 原生线性、径向、扫角渐变；图片已有 provider、异步 formatter、fallback、错误与就绪回调。

以下仅列代码确认的缺口。“需整体替换”表示已有兜底扩展点，但缺少局部覆盖能力。路径除公共入口外均位于 `lib/src/core/`；S／M／L 分别表示小范围、跨模块、跨绘制或运动管线改造。本次只读检查，未修改文件、执行 git、获取依赖或运行测试。
