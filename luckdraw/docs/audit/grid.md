# 自定义能力盘点：九宫格

> 只读审计原文（2026-11，Codex 逐条核对代码，含 文件:行号）。代码此后有变动，行号仅供定位；已落地项见 CHANGELOG 与 docs/E1_E2_DEVICE_REPORT.md。

已经开放得好的点：

- `GridOptions.motion` 已开放加减速曲线、时长、速度、时间基准、停止求解器和单帧时间上限；没有发现不可替换的 `LuckyEasings.xxx` 调用。
- 行列、跨行跨列、间距、背景块内边距，以及背景、描边、圆角、阴影、字体、图片尺寸等均可配置。
- 奖品和按钮都有局部 `GridCellPainter`；另有四个位置的 layer、绘制前后钩子、Widget overlay 和整体 renderer 替换入口。
- 自定义 renderer 能取得配置、布局、图片及通知器；`GridLayout` 已公开完整命中矩形、普通/激活视觉、图片位置和文字行。
- 选奖器、随机源、指定目标、附加圈数、异步取奖、暂停恢复均已开放；阶段、激活项、图片失败和图片就绪已有回调。
