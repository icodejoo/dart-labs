# MET2：预算标定与稳定性规则（2026-11-10）

纯离线，沿用MET/FIN选定的33个样本（11场景各三轮）；设备vivo V2417（Android 16）/60Hz。PERF五场景+DEV其余，不是同一APK重测，不是跨设备保证。

全部130个保存稳态窗口约60fps（59.829927–60.176516），帧交付完整，无真实丢帧（timeline交付口径，非独立面板呈现测量）。25个Raster窗口受vsync背压污染且与绘制内容无关，参照方块65个中也有9个；污染分类和RSS门禁保持MET/FIN规则。成本只用正式集合22个未污染窗口，所有27个主窗口检查交付。

## 规则与可重复性

比例极差≤0.01；时间中位数<0.5ms时极差≤0.15ms；其余时间/字节相对极差≤30%。近零比例的相对极差无意义；绝对容差抑制小基数放大，但不豁免回归预算。RSS仍仅按绝对上限。

正常compare只读冻结预算，不在每次回归中自动放宽。显式--calibrate仅输出建议：至少2个未污染且稳定的时间指标，预算=max(中位数×1.1向上取整到0.001ms，有来源的历史标定下限)。下限不高于MET2开始时已批准值；冻结来源、初始设计快照与MET前目标分别保存在budgets.status.json.met2。比例/GC/RSS不重标。不存在15%放宽截止线；不稳定或样本不足标不确定，需补跑。

最初设计目标来自DEV保存的design_budgets.json；MET冻结目标含FIN批准值和历史更严校准，另列为target。RSS改口径不能与旧0.5MiB直接比，继续使用FIN 1.5MiB。冷首帧40.378ms仅信息，4ms旧估算不标达成，待空白页基线。

硬门禁对每个未污染窗口单独检查合计P99≤12.0ms且UI P99≤4ms；任一超标即失败，优先于不确定。使用保存的同帧合计P99，绝不将两个独立P99相加；12ms给16.67ms至少留4.5ms。
